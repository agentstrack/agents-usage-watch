# Security

Agents Usage Watch reads files that coding agents write on your Mac and edits their status line settings when you
click Set Up. If you find a way it could expose credentials, run unexpected commands, or damage those settings,
please report it privately instead of opening a public issue: use GitHub's
[private vulnerability reporting](https://github.com/agentstrack/agents-usage-watch/security/advisories/new).

Please include the macOS version, the steps to reproduce, and what an attacker could do. You'll get a reply within a
week, and a fix and credit (if you'd like it) once it's resolved.
